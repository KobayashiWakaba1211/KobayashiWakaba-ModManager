# 角色别名配置说明

编辑同目录的 `character-aliases.json`，按游戏 ID、角色目录名称维护别名。角色目录名称必须与管理器中的角色名称一致。

```json
{
  "endfield": {
    "陈千语": ["Chen Qianyu", "chen", "陈"]
  }
}
```

在数组中添加别名，以英文逗号分隔；使用 UTF-8 编码，遵守 JSON 格式（不能添加注释或尾随逗号）。文件内已有游戏数据不需要删除。

游戏 ID：终末地 `endfield`、星穹铁道 `starrail`、鸣潮 `wuthering`、绝区零 `zenless`、异环 `neverness`、原神 `GenshinImpact`。原神没有 QAQManager 对照数据，初始为空，可自行补充。

匹配时忽略大小写及非字母数字字符，名称和拼音也参与包含匹配；多个角色命中时不自动选择，需在导入窗口手动确认。匹配候选仅包括当前游戏已有角色。别名可能引起误匹配，尤其是很短的别名，请谨慎添加。

配置在编译时嵌入程序：修改后需要重新构建，已有安装包不会自动更新。该文件不是安装后可直接编辑生效的设置。角色数据取自用户授权使用的 QAQManager 角色配置；匹配代码独立编写。
